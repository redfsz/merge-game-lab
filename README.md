# Merge Lab · 游戏数值实验室

在线访问：https://redfsz.github.io/merge-game-lab/

配置驱动的订单节奏、统计分析、生成器负载、配方追溯与 7×8 机器人合成棋盘。

机器人按可编辑计划执行：金币优先、易完成优先或随机选单，每交付一单推进计划。订单需求和奖励可自行配置；默认金币标注为演示值，不来自工作簿。仓库默认7格，可调整容量，支持自动整理和详细原因日志。初始棋盘可以布置，场景JSON可导出、导入。图表、表格可点击追溯，术语和图标附问号解释。

本站为配置快照，不实时连接工作簿；更新工作簿后需重新导出并发布。网页手动设置保存在当前浏览器，不回写原表或公共站点。当前店铺采用正式递推复算，其他店铺保留已保存缓存，详情见网页的数据源页面。

棋盘采用离散期望产出，时间为演示节拍；尚未接入概率掉落、自然体力恢复及实际游戏资源。生成器CD默认无限，可预设次数和秒数，但当前仅保存设置，不执行冷却等待。

网页使用原生 HTML、CSS、JavaScript，相对资源路径，无构建依赖。GitHub Pages 从 main 分支根目录发布。
